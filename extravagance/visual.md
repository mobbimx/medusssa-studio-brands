# Extravagance — Identidad Visual

## Colores
Paleta mínima y de alto contraste, look nocturno "dorado sobre negro".

| Rol | Color | HEX | Uso |
|-----|-------|-----|-----|
| Primario | Amarillo Extravagance | `#F8D808` | Logo, títulos, acentos, CTA |
| Base oscuro | Negro | `#0A0A0A` | Fondos, ambiente nocturno |
| Neutro claro | Blanco | `#FFFFFF` | Texto secundario, bajada del logo |
| Apoyo (opcional) | Dorado profundo | `#C9A800` | Sombras/degradados sobre el amarillo |

- **Combinación base:** amarillo + negro. El blanco es el tercer color de apoyo.
- El amarillo se usa como **luz** (títulos, línea de acento, CTA), nunca como fondo
  de área grande sobre foto.
- Fondos siempre oscuros para conservar el aire de club nocturno.

## Tipografías
La marca no tiene tipografía definida. El logo usa un lettering deportivo/futurista,
en itálica, con recortes tipo velocidad (la "E" invertida es un rasgo de marca — no
recrearla en textos, es exclusiva del logo).

**Recomendación (por validar):**
- **Titulares:** una sans condensada, itálica y con carácter, que dialogue con el logo.
  Opciones libres: *Saira Condensed*, *Rajdhani*, *Michroma*, *Oswald* (itálica).
- **Texto / cuerpo:** una sans neutra y legible. Opciones libres: *Inter*, *Montserrat*,
  *Poppins*.

## Logo
Archivos en `referencias/`:
- `logo-horizontal.png` — logotipo completo HD (isotipo + "EXTRAVAGANCE" + "CLUB FOR MEN").
- `isotipo.png` — solo el símbolo (flama/estela). Ideal para avatar, sellos y marcas de agua.
- `logo-referencia.jpg` — referencia adicional.

**Reglas de uso:**
- Usar preferentemente sobre **fondo negro/oscuro**.
- Respetar aire alrededor; no deformar ni recolorear.
- Sobre fotos, colocar el logo en zona limpia y oscura, o con ligera sombra.
- El isotipo funciona solo como firma en la esquina de historias y videos.

## Lineamientos gráficos
- **Estética:** noche, luz baja, dorado, siluetas, contraluces, humo, texturas de barra.
- **Fotografía:** ambientes iluminados, detalle de botellas/copas/hielo, privados montados.
  Personas solo con consentimiento; preferir manos, siluetas y espacios.
- **Acento gráfico:** una **línea/estela amarilla** (inspirada en el isotipo) como
  elemento recurrente para títulos y separadores.
- **Formato base:** vertical **9:16** para historias/reels; **4:5** para feed.
- El amarillo siempre destaca sobre negro para máxima legibilidad y recordación.
