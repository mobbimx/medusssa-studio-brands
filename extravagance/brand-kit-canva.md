# Extravagance — Brand Kit para Canva

Todo listo para crear el Brand Kit de Extravagance en Canva (la API de Canva no permite
crearlo por código, se crea a mano en 2 minutos con estos datos).

## 1. Colores
| Rol | HEX | Nombre en Canva |
|-----|-----|-----------------|
| Primario | `#F8D808` | Extravagance Amarillo |
| Base oscuro | `#0A0A0A` | Negro Club |
| Neutro | `#FFFFFF` | Blanco |
| Apoyo | `#C9A800` | Dorado Profundo |

## 2. Tipografías
- **Títulos:** *Bebas Neue* o *Anton* (condensada, impacto) — o *Saira Condensed Italic*
  para parecerse al lettering deportivo del logo.
- **Subtítulos / cuerpo:** *Montserrat* o *Inter*.
- (En las plantillas HTML se usó Bahnschrift + Segoe UI; en Canva el equivalente más
  cercano y gratuito es Saira Condensed / Montserrat.)

## 3. Logos (subir al Brand Kit)
Descárgalos del repo o usa estas URLs directas (repo público):
- Logo horizontal: `https://raw.githubusercontent.com/mobbimx/medusssa-studio-brands/master/extravagance/referencias/logo-horizontal.png`
- Isotipo: `https://raw.githubusercontent.com/mobbimx/medusssa-studio-brands/master/extravagance/referencias/isotipo.png`

## 4. Cómo crearlo en Canva (paso a paso)
1. Entra a Canva → esquina inferior izquierda: **Brand** (o canva.com/brand/settings).
2. **+ Add new** → nombra el kit **"Extravagance"**.
3. **Brand Colors** → agrega los 4 HEX de arriba.
4. **Brand Fonts** → asigna fuente de títulos y de cuerpo.
5. **Logos** → sube `logo-horizontal.png` y `isotipo.png`.
6. Guarda. Al generar diseños, elige el brand kit **Extravagance**.

> Cuando esté creado, guardar el `brand_kit_id` junto a los demás (ver sistema de
> contenido Canva de Medusssa) para reutilizarlo en la generación automática.

## 5. Carpeta en Canva (estructura sugerida, igual que las otras marcas)
```
EXTRAVAGANCE/
  ├─ Stories
  ├─ Posts Facebook
  ├─ Anuncios - Pauta
  └─ TikTok
```
