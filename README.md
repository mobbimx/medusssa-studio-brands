# Medusssa Studio — Brand Knowledge Base

Repositorio centralizado de información, identidad y estrategia de contenido para cada marca gestionada por **Medusssa Studio**.

## Estructura

```
marketing/          - Proyecto de fidelización y captación (índice y benchmarks)
peachystudio/       - Peachy Studio Nails
mobbitrips/         - Mobbitrips (alojamientos flexibles)
salones-aurora/     - Salones Aurora (eventos)
alpha-fitness/      - Alpha Fitness
extravagance/       - Extravagance
```

## Proyecto activo — Mercadotecnia de fidelización y captación

Ver [`marketing/README.md`](marketing/README.md) para el índice, la metodología y los benchmarks transversales.

Cada negocio tiene su propia carpeta `marketing/` y **se trabaja por separado, sin cruzar ideas entre marcas**:

| Negocio | Carpeta |
|---------|---------|
| Alpha Fitness | [`alpha-fitness/marketing/`](alpha-fitness/marketing/) |
| Mobbitrips | [`mobbitrips/marketing/`](mobbitrips/marketing/) |
| Peachy Studio | [`peachystudio/marketing/`](peachystudio/marketing/) |
| Salones Aurora | [`salones-aurora/marketing/`](salones-aurora/marketing/) |

> Extravagance queda fuera del alcance de este proyecto.

## Propósito

Cada carpeta contiene la información de marca necesaria para:

- Mantener congruencia gráfica y respetar la identidad visual
- Generar contenido profesional alineado al tono de voz
- Documentar estrategias de publicidad y redes sociales
- Servir como fuente de verdad para la creación de contenido

## Contenido por marca

Cada carpeta incluye (según disponibilidad):

| Archivo | Descripción |
|---------|-------------|
| `identidad.md` | Voz de marca, tono, arquetipos, vocabulario |
| `visual.md` | Colores, tipografías, logo, lineamientos gráficos |
| `servicios.md` | Catálogo de servicios/productos |
| `estrategia.md` | Estrategia de contenido y redes sociales |
| `referencias/` | Material visual de referencia |
