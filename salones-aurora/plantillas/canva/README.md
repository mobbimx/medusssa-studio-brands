# Aurora Salones — Editables para Canva

`aurora-salones-8-plantillas.pptx` — las 8 plantillas de feed como **PPTX de 8 páginas**
(1080 × 1350 px), pensado para importarse a Canva.

## Por qué PPTX y no PNG

Canva importa PPTX conservando **cada elemento por separado y editable**: cajas de texto
reales, imágenes, formas y colores. Un PNG entraría como una estampa plana.

Lo que llega editable a Canva:
- Todos los textos, con su fuente (Playfair Display / Poppins), tamaño, color y alineación.
- El logo, las fotos y la trama de curvas de nivel, como imágenes independientes.
- Chips de fecha, marco polaroid, botón pill, estrellas y barra de cierre, como formas.

## Cómo importarlo

**Opción A — desde Canva:** *Crear diseño → Importar archivo* y sube el `.pptx`.

**Opción B — por URL:** el archivo está en el repo público, así que se puede importar
directo desde:
```
https://raw.githubusercontent.com/mobbimx/medusssa-studio-brands/claude/aurora-salones-contenidos-fny4w3/salones-aurora/plantillas/canva/aurora-salones-8-plantillas.pptx
```

## Después de importar

1. **Instala las fuentes de marca** en el brand kit: *Playfair Display* y *Poppins*
   (las dos están gratis en Canva). Si Canva sustituye alguna al importar, se corrige
   seleccionando el texto y eligiendo la fuente correcta.
2. **Guarda cada página como plantilla de marca** para que el cliente solo cambie los
   campos `[entre corchetes]` y la foto.
3. Los colores de marca están en `../../brand-kit-canva.md`.

## Nota
Las guías de edición (*"Campos editables: …"*) **no** se incluyeron en el PPTX: en Canva
los campos se ven directamente entre corchetes. Los PNG de `../` sí las traen porque ahí
sirven de referencia al editar el HTML.
