## Pendientes al editar en Canva
1. **Cambiar las zonas `[ Foto real ]`** por fotografía real de las propiedades / Xalapa.
2. **Rellenar los `[ placeholders ]`** de la reseña (08) y las cifras (09) con datos reales.
3. Verificar fuentes: si Comfortaa/Nunito no quedaron exactas en la importación,
   aplicarlas desde el Brand Kit o el panel de fuentes.
4. Para carruseles (01, 04, 05, 10): esta es la **portada**; duplicar página para las
   siguientes láminas.

## Fuente
HTML importable en `./PropNN.html` (una página Canva cada uno,
`data-document-role="page"`), generado desde los artboards del lienzo de revisión.
