# Mobbitrips — Brand Kit para Canva

Datos listos para crear el Brand Kit de Mobbitrips en Canva (se crea a mano en 2 min;
la API de Canva no permite crear el kit por código).

## 1. Colores
| Rol | HEX | Nombre en Canva |
|-----|-----|-----------------|
| Primario (acento) | `#ED6864` | Mobbi Coral |
| Secundario (soporte) | `#706F6F` | Mobbi Gris |
| Base clara | `#FFFFFF` | Blanco |
| Base texto | `#333333` | Gris oscuro texto |

> Coral solo como **acento**; gris de soporte; el protagonista es la **foto del espacio**.

## 2. Tipografías
- **Títulos:** *Comfortaa* (Light) — mantiene el aire del logo "Mobbi".
- **Cuerpo:** equivalente a *Microsoft JhengHei UI*; en Canva usar *Inter* o *Noto Sans* (gratuitas, muy cercanas).
- **Editorial/secundaria:** equivalente a *Myriad* → en Canva *Source Sans Pro* o *Open Sans*.

## 3. Logos (subir al Brand Kit)
- **Pendiente:** subir el logo vectorial de Mobbitrips a `referencias/` para poder
  cargarlo al Brand Kit y usar la URL `raw.githubusercontent.com` (como en Extravagance).

## 4. Cómo crearlo en Canva (paso a paso)
1. Canva → **Brand** (canva.com/brand/settings) → **+ Add new** → nómbralo **"Mobbitrips"**.
2. **Brand Colors** → agrega los HEX de arriba.
3. **Brand Fonts** → títulos *Comfortaa*; cuerpo *Inter*.
4. **Logos** → sube el logo (cuando esté disponible).
5. Guarda y, al generar diseños, elige el brand kit **Mobbitrips**.

> Al crearlo, guardar el `brand_kit_id` para reutilizarlo en la generación de plantillas.

## 5. Carpeta en Canva (estructura sugerida)
```
MOBBITRIPS/
  ├─ Stories
  ├─ Posts (Feed)
  ├─ Carruseles
  ├─ Propietarios (B2B)
  └─ Anuncios - Pauta
```
