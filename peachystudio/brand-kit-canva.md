# Peachy Studio — Brand Kit y plantillas en Canva

El Brand Kit **“PeachyStudio”** ya existe en la cuenta de Canva de Medusssa Studio
(`brand_kit_id: kAGo3G1GO_o`). Lo que falta es dejarlo completo y montar sobre él
las plantillas de historia como **Brand Templates** reutilizables.

## 1. Revisar que el Brand Kit tenga esto

**Colores** (Brand → Colores):

| HEX | Nombre |
|-----|--------|
| `#fe42a2` | Peachy Rosa |
| `#ffb7f0` | Rosa Suave |
| `#f7daff` | Lila Peachy |
| `#5e17eb` | Morado Retro |
| `#fec900` | Amarillo Peachy |
| `#ffffff` | Blanco |

**Fuentes** (Brand → Fuentes):

| Rol | Fuente |
|-----|--------|
| Titulares | Retro Vintage regular |
| Frases / script | Adam Script |
| Etiquetas y datos | Retropix |

**Logos** (Brand → Logos): subir la versión **apilada** y la **horizontal**,
ambas en PNG con fondo transparente, exportadas del Canva `ARCHIVOS PEACHE` (página 1).

## 2. Estructura de carpetas sugerida

```
PEACHY STUDIO/
  ├─ 00 · PLANTILLAS MAESTRAS   <- las 4 plantillas de historia (no se editan)
  ├─ Historias                  <- copias publicadas del día a día
  ├─ Posts / Carruseles
  ├─ Impresos                   <- tarjetas, menú, gift cards
  └─ Recursos                   <- logos, fondos, caritas, margaritas
```

## 3. Cómo montar cada plantilla

1. Crear un diseño nuevo **Historia de Instagram (1080 × 1920 px)**.
2. Reproducir la maqueta correspondiente de `plantillas/png/` usando los colores
   y fuentes del Brand Kit.
3. Marcar las guías de zona segura: una en **300 px** desde arriba y otra en
   **290 px** desde abajo. Nada importante fuera de ahí.
4. Nombrar cada capa de texto con el nombre del campo editable
   (`ETIQUETA`, `TITULAR`, `PRECIO`, `FOTO`…) para que quien edite no se pierda.
5. Bloquear (candado) todo lo que **no** debe moverse: fondo, logotipo, pie de contacto.
6. Guardar como **Brand Template** (menú → *Publicar como plantilla de marca*)
   dentro de `00 · PLANTILLAS MAESTRAS`.
7. Para publicar, siempre *Usar plantilla*, nunca editar la maestra.

## 4. Reglas de edición para quien las use

- Solo se tocan los campos desbloqueados.
- Los textos no crecen: si no cabe, se acorta el copy, no se achica la fuente.
- Las fotos entran arrastrándolas sobre el marco (Canva las recorta solo).
- Máximo 3 emojis por pieza, de la lista de marca: 💗 🌼 😊 ⭐ 💅 📲
- Nunca cambiar el color del logotipo ni ponerle sombra.

## 5. Equivalencias por si falta una fuente

Si Retro Vintage, Adam Script o Retropix no aparecen en algún dispositivo, los
sustitutos más cercanos dentro de Canva son:

| Fuente de marca | Sustituto en Canva | Sustituto web (usado en las maquetas de este repo) |
|-----------------|--------------------|-----------------------------------------------------|
| Retro Vintage regular | Bagel Fat One | Bagel Fat One |
| Adam Script | Yellowtail | Yellowtail |
| Retropix | Pixelify Sans | Pixelify Sans |
| Apoyo / cuerpo | Poppins o Fredoka | Fredoka |
