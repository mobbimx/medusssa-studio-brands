# SEMANA 1 — Diseño y producción de material

### 🗓️ Día 1 · Lunes — Arranque

| | Tarea |
|---|---|
| 🟠 | **Junta con la dueña.** Presentar el programa y cerrar **las 4 decisiones** *(usar `presentacion-duena.md`)* |
| 🟠 | Pedir el costo de material por servicio y por uña decorada |
| | Cotizar imprenta: 2 proveedores, tiempo de entrega por escrito |
| | Arrancar arte de la tarjeta |

> **Las 4 decisiones no bloquean el arte.** La tarjeta no nombra los premios —dice ✦ *sorpresa* y ★ *premio mayor*—, así que el diseño avanza aunque la dueña todavía no elija entre cromo y aceite. **Lo único que sí hay que cerrar hoy es la fecha de cierre de la ventana.**

### 🗓️ Día 2 · Martes — Arte v1

| | Tarea |
|---|---|
| | Arte de la tarjeta, versión 1 *(frente y vuelta)* |
| | **Pedir el sello** — es el artículo con más tiempo de entrega |
| | Definir el plumón de respaldo por si el sello no llega |

### 🗓️ Día 3 · Miércoles — Arte v2

| | Tarea |
|---|---|
| | Revisión interna y ajustes |
| | Prueba de impresión casera: **¿se lee el nombre escrito a mano? ¿cabe el sello en la casilla?** |
| | Enviar a aprobación de la dueña |

> **La prueba en papel no se salta.** Un arte que se ve bien en pantalla puede tener casillas donde el sello no cabe — y eso solo se detecta imprimiendo y sellando.

### 🗓️ Día 4 · Jueves — 🎯 HITO · A imprenta

| | Tarea |
|---|---|
| 🟠 | **Aprobación del arte** |
| | **Archivo a imprenta.** Mínimo 40 tarjetas |
| | Confirmar fecha de entrega **por escrito** |

### 🗓️ Día 5 · Viernes — Gráficos secundarios

| | Tarea |
|---|---|
| | Portada del highlight *"Tu tarjeta"* |
| | Arte y texto del Google Post |
| | Línea nueva para la bio de Instagram |
| | Plantilla de texto en pantalla para los videos *(tipografía, tamaño, posición)* |

### 🗓️ Días 6–7 · Fin de semana

**Colchón.** Si algo de la semana se atrasó, se recupera aquí.

# RIESGOS

| Riesgo | Probabilidad | Plan B |
|--------|--------------|--------|
| **La imprenta se atrasa** | 🔴 Alta | Cotizar 2 proveedores el Día 1. Alternativa: imprimir 15 tarjetas en digital para el rodaje y la semana 0, y el tiraje completo llega después |
| **El sello no llega a tiempo** | 🟡 Media | Plumón definido desde el Día 2. Se ve casi igual en cámara |
| **La clienta del rodaje cancela** | 🟡 Media | Segunda cita agendada el mismo día |
| La dueña no cierra las 4 decisiones el Día 1 | 🟡 Media | El arte avanza igual. Solo la fecha de cierre es urgente |
| El arte necesita más vueltas | 🟢 Baja | El colchón del fin de semana lo absorbe |

> **El riesgo real es uno solo: la imprenta.** Los otros cuatro tienen plan B que no mueve la fecha.
